# Contributing to LensQA

Thanks for helping improve LensQA.

## Start here

1. Check existing issues before opening a new one.
2. Fork the repository and create a focused branch.
3. Install dependencies with `npm install`.
4. Run `npm run build` and `npm test`.
5. Open a pull request explaining the problem, solution, and verification.

## Visual changes

Run:

```bash
npm run test:visual
```

Update snapshots only when the UI change is intentional, and include the resulting diff in the pull request.

## Scope

Prefer small changes that solve a demonstrated problem. Avoid speculative abstractions, unrelated cleanup, or new dependencies when the platform already provides the required capability.

## Conduct

Be constructive, specific, and respectful. Harassment, discrimination, and abusive behavior are not accepted.
